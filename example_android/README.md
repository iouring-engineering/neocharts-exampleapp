# NeoCharts — Android Example

Demonstrates the **native add-to-app** integration style: a cached Flutter engine mounting
`NxtChartPage`, driven from Kotlin over `nxtchart/data`.

## Run it

Open in Android Studio, or:

```bash
./gradlew installDebug
```
