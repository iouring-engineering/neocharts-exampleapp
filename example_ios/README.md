# NeoCharts — iOS Example

Demonstrates the **native add-to-app** integration style: a cached Flutter engine mounting
`NxtChartPage`, driven from Swift over `nxtchart/data`.

## Run it

```bash
pod install
open example_ios.xcworkspace
```

Then run from Xcode.
